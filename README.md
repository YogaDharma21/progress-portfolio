# Progress Portfolio

A personal portfolio website created as a mini project for the **UKM Progress Web Developer Class**

## Features

- **Hero Section** - Introduction with name and role
- **Projects Section** - Display of completed projects with descriptions and links
- **Skills Section** - Showcase of technical skills (Laravel, React, Node.js, Tailwind)
- **Contact Form** - Functional contact form with validation
- **Responsive Design** - Works on desktop and mobile devices
- **Smooth Navigation** - Anchor links with scroll offset

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure

```
progress-portfolio/

│   ├── style.css      # Main styles

```

## Getting Started

1. Clone or download this repository
2. Open `index.html` in any web browser
3. No build step or server required

## Customization

- **Colors** - Edit CSS variables in `css/style.css` (`:root` section)
- **Content** - Modify the HTML in `index.html`
- **Styling** - Adjust styles in `css/style.css`
